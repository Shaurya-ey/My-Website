<h1 align="center">Personal Portfolio - Shaurya Pandey</h1>
My portfolio site, built with plain HTML, CSS and JavaScript. No framework, no build step — just the browser, a space theme and a lot of tinkering.

## Features
- Space-themed design with a particle-network background and glass navbar
- Projects section with a Software / Hardware filter and photo cards that auto-slide on hover
- Live GitHub section — real contribution graph, profile stats and language breakdown pulled from the GitHub API
- Shared guestbook and visitor counter backed by Supabase
- Hobbies section, scroll animations, responsive layout
- Deployed on Vercel at [Portfolio website link](https://shauryapdev.vercel.app)

---

## Tech

- HTML, CSS, vanilla JS
- GitHub API (live data)
- Supabase (guestbook + visit tracking)

---

## AI usage

Built mostly by me, but I used AI as a helper for about 30% of it — mainly to debug tricky CSS/JS issues (the contribution-graph timezone bug took me three tries), explain what my git errors meant when I broke something, and sanity-check the Supabase setup. The theme, layout and ideas are mine.
